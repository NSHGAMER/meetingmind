# Hackathon demo script (~4 min)

**Before**: backend + Hindsight running, *Settings → Test connection* is green. Register a fresh account.

1. **Hook (15 s)** — "Meeting tools summarise one meeting. MeetingMind remembers *all* of them."
2. **Interaction 1 – no memory (30 s)** — Dashboard → *Load demo data* (marked **sample**). Open *Project review* → **Prepare my meeting → Compare**. Point at the grey *Generic briefing — no memory used* banner: advice is generic.
3. **Meeting 1 (45 s)** — Open *Project kickoff* (Oct 20) → tick the privacy box → *Analyse notes*. Show the review screen: budget ₹5 lakh, 60 days, monthly payments, Robert's commitment. Remove nothing → **Confirm & save to memory**. Say: "Only confirmed facts reach Hindsight."
4. **Interaction 2 – memory-powered (45 s)** — Prepare the review meeting → **PREPARE MY MEETING**. Show the indigo *Retrieved from Hindsight* banner, the citations (`M1 · Oct 20 · Project kickoff`), the overdue requirements-document commitment, and the labelled *AI recommendation* sections.
5. **Meeting 2 (45 s)** — Analyse+confirm *Project follow-up* (Oct 27). Highlight: the document is mentioned as "still pending" but **not** marked complete; a delivery-timeline concern is captured.
6. **Interaction 3 – evolving (30 s)** — Prepare again: the concern appears, two previous meetings are cited, talking points now include the revised timeline.
7. **Proof it's real (30 s)** — *Memory Intelligence*: recall/retain counts from logged calls, the exact memories behind each briefing, activity timeline. Contact page → *Relationship intelligence* generated from records.
8. **Safety (15 s)** — stop Hindsight and press Prepare: clear *Hindsight memory integration error*, no fake results.

**Judging map**: Innovation (relationship intelligence, supersession, confirm-before-remember) · Hindsight use (bank-per-user, documents, tags, provenance) · Technical (tests, error handling) · UX (prepare workspace) · Impact (forgotten commitments).
